# Contributing

Open an issue with the component name, expected behavior, actual behavior, and a
small reproduction using synthetic data. Do not include access keys, private
projects, customer records, or Plus materials in public issues or pull requests.

Run `npm test`, `npm run typecheck`, and `npm run build` before proposing changes.
Check affected controls in light and dark themes, with a keyboard, and at narrow
screen sizes. Preserve existing APIs and required third-party notices.

This repository is the free component distribution, not the Compass website's
administration, authentication, billing, or membership backend. It has no
production environment variables or database migrations.
