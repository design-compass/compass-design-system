# button

## Do

- 한 작업 영역에서 가장 중요한 행동 하나에만 Primary 버튼을 사용합니다.
- ‘저장’, ‘초대 보내기’처럼 실행 결과를 예측할 수 있는 동사로 라벨을 씁니다.
- 처리 중에는 진행 상태를 알리고 중복 실행을 막되, 버튼의 폭과 위치는 유지합니다.
- 아이콘만 있는 버튼에는 접근 가능한 이름을 제공하고 키보드 포커스가 보이게 합니다.

## Don't

- 같은 영역의 모든 버튼을 강조하거나, 일반적인 행동에 위험 색상을 사용하지 않습니다.
- 결과가 불분명한 ‘확인’만 반복하거나, 삭제와 저장처럼 다른 행동에 같은 라벨을 쓰지 않습니다.
- 페이지 이동을 클릭 이벤트만 있는 일반 버튼으로 구현하지 않습니다. 이동에는 링크의 의미를 유지합니다.
- 비활성화한 이유를 숨기거나, 마우스 호버에서만 실행에 필요한 정보를 보여주지 않습니다.
