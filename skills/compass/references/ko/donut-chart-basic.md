# donut-chart-basic

## Do

- 같은 전체를 이루는 음수가 아닌 부분의 비율에 사용하고 기준 전체와 기간을 표시합니다.
- 항목명과 값·비율을 함께 제공하고 작은 차이를 비교해야 하면 막대 차트를 선택합니다.
- 가운데 빈 공간은 유지하고 조각의 비율을 같은 전체 기준으로 계산합니다.

## Don't

- 서로 겹치는 범주나 서로 다른 전체의 값을 하나의 파이에 합치지 않습니다.
- 작은 조각을 과도하게 나누거나 3D·기울임 효과로 각도와 면적을 왜곡하지 않습니다.
- 가운데 공간 때문에 수치를 생략하거나 조각 사이 간격을 지나치게 키워 비율을 흐리지 않습니다.
