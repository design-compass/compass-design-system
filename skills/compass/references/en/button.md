# button

## Do

- Use one primary button for the most important action in a task area.
- Use action labels such as Save or Send invitation that make the outcome predictable.
- Show a pending state and prevent duplicate submissions while keeping the button's width and position stable.
- Give icon-only buttons an accessible name and keep keyboard focus visible.

## Don't

- Do not emphasize every button in an area or use destructive styling for ordinary actions.
- Do not repeat vague labels such as OK or use the same label for different actions such as deleting and saving.
- Do not implement navigation solely as a button click handler. Preserve link semantics for navigation.
- Do not hide why an action is unavailable or reveal essential information only on hover.
